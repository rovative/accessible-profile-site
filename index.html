About

I'm a BSc (Hons) Computer Science graduate from the University of Hertfordshire, with a focus on front-end development, accessibility, and building clean, usable interfaces.

My main personal project is CreatorFlow (opens in new tab) — a full-stack social media scheduling web app built with Next.js, React, TypeScript, and Supabase.

I care about writing code that works properly: semantic HTML, real keyboard navigation, sufficient colour contrast, and layouts that hold together across screen sizes and devices.
